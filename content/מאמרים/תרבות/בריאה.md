# בריאה

את היוֹם השׁמִינִי
בּרא למשוֹררִים
שיכתבוּ בּשִיר אחָד
לעם אחָד
את ספֶר הספַרִים
אחד מהם פָּשַׁע
סיפּר סיפּוּרים אחרִים
בגללוֹ שׂרף את כּוּלָם
נותרו אודִים עשׁנִים
הם מזכִּירִים לנוּ בּרגעים קטנִים
את להט החֶרֶב הַמִּתְהַפֶכֶת
שׁמתִירה לחוּש טעמה של שִׁירה
בּמָסֶכֶת כּאב יצִירה
מהגירוּש נותרו צלמי רמזים
כּוֹח הרָצוֹן
וצער הייאוּש
ביניהם גוֹסס חוֹפש הבּחִירה
זכוֹר את היוֹם השׁמִינִי לקוֹדשׁוֹ
כּי בּוֹ ידעת טעם כּפִירַה.
